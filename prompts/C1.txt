COMMANDS TO USE FOR THIS REPO
- Install dependencies: `pnpm install`
- Ensure Payload packages:  
  `pnpm add -w payload@3.63.0 @payloadcms/next@3.63.0 @payloadcms/db-postgres@3.63.0 @payloadcms/richtext-lexical@3.63.0`
- Start infra: `docker compose up -d`
- Run DB migrations: `pnpm payload:migrate`
- Start dev server: `pnpm dev`
- DO NOT use `pnpm db:migrate` or `pnpm seed:demo` in this repo, these scripts do not exist in the current snapshot.
