### 2️⃣ Features & Modules Summary (tự động tổng hợp)

Hãy nhóm và liệt kê đầy đủ các **feature / module / hệ thống** đã được bàn luận trong hội thoại, theo block rõ ràng.

Gợi ý nhóm (chỉ dùng nếu có trong hội thoại):

#### 2.1. SaaS Multi-tenant & Domain Routing
- Tenant / Site model (mỗi khách hàng có thể có nhiều site).
- Domain mapping: subdomain + custom domain → site.
- Multi-tenant isolation: data, media, config per site.
- Export 1 site thành Standalone (code + data tách rời SaaS).

#### 2.2. Auth, RBAC & Workflow
- Role system:
  - `saasOwner`, `saasAdmin`
  - `siteOwner`, `siteAdmin`, `siteEditor`, `siteTranslator`, `siteViewer`
- Workflow content:
  - Draft → Pending → Published (+ khả năng custom step trung gian do saasOwner cấu hình).
  - Quy định khi quyền workflow của user thấp hơn tài liệu thì chỉ được xem, không được sửa.
- Quyền Export:
  - Mặc định `siteOwner` / `siteAdmin` **không** được export, chỉ khi saasOwner cấp quyền.

#### 2.3. I18n & Ngôn ngữ
- Phân biệt rõ:
  - **Ngôn ngữ website** (site locales, có license, slug theo locale).
  - **Ngôn ngữ giao diện quản trị** (adminLanguage per user, đọc từ file `.json`).
- SiteLocales:
  - Bật/tắt per locale theo license (`isPaid`).
  - Slug mapping per locale: `/tin-tuc`, `/du-an`, `/tuyen-dung`, `/san-pham`, `/news`, `/projects`, `/careers`, `/products`...
- Admin i18n:
  - File `admin.vi.json`, `admin.en.json`, … auto-detect.
  - Toàn bộ label admin, error, NotFound, GlobalError, v.v. dùng i18n, không hard-code.

#### 2.4. Content Model & Theme System
- Collections chính:
  - Tenants, Sites, Themes, Industries, DemoContentSets
  - Taxonomies, Posts (news/project/job/...), Products
  - Pages + Blocks (section-based page builder)
  - Settings, ThemeSettings, AiSettings, ThemeOverrides
  - ContentAttributes (custom flags/attributes)
  - Media, Forms, Leads
  - SearchIndex, AuditEvents, Extensions, SiteExtensions
- Theme:
  - Theme `company-industrial` với `theme.config.ts`, pageBlueprints, section default.
  - Theme base trong `packages/themes`, auto-sync vào collection `themes`.
- Page builder & Blocks:
  - Hero, ServicesGrid, CapabilitiesGrid, FeaturedProjectsCarousel, NewsTabs, PartnersCarousel, CTA, Form...
  - Visibility per device (Desktop/Tablet/Mobile), layoutType (row/grid/slider), animation presets.
  - Responsive 100% cho tất cả section (desktop/tablet/mobile dọc & ngang).

#### 2.5. SEO, Search, Preview & Staging
- SEO:
  - Tự động meta title/description/og từ nội dung (không bắt nhập tay).
  - JSON-LD cho Article/NewsArticle/JobPosting/Product.
  - Sitemap.xml per site/locale, RSS feed tin tức.
- Search:
  - Collection `search-index` nhỏ gọn, index riêng cho posts/products/pages.
  - Route `/search` theo `site + locale`, nhóm kết quả theo loại (Tin tức / Dự án / Tuyển dụng / Sản phẩm / Trang).
- Preview & Staging:
  - Preview token (JWT) ngắn hạn + `/api/preview` + draftMode.
  - Staging domain per site (nếu có), preview đúng slug + locale + domain.

#### 2.6. Forms, Leads & Automation
- Form builder (Liên hệ / Tư vấn / Báo giá / Tuyển dụng…).
- Leads collection + trạng thái lead (mới / đang xử lý / chốt / fail).
- Rate limit + honeypot tránh spam.
- (Nếu đã bàn) Automation rules: trigger onFormSubmit/onLeadCreated → email/webhook/assign.

#### 2.7. Logging, Audit & Security
- AuditEvents: ghi lại create/update/delete, publish, đổi quyền, login fail nhiều, export.
- Logging JSON (có tenantId, siteId, userId) cho mọi action quan trọng.
- Security:
  - Rate limiting cho login, form, export.
  - CSRF cho action nhạy cảm.
  - Security headers + CSP.
  - Upload policy (mime, size, path isolation per tenant/site).

#### 2.8. DevOps, Export & Extension
- Dev & CI/CD:
  - Turborepo, script `dev`, `build`, `seed:demo`, `db:migrate`.
  - Dockerfile, docker-compose, healthcheck `/healthz`.
- Export Standalone:
  - Service `exportSiteToBundle` + API `/api/sites/[siteId]/export` (role + rate limit).
  - Bundle zip: code + data JSON + seed script + docker-compose cho standalone.
- Extension / Marketplace skeleton:
  - `extensions` + `site-extensions` + license/isPaid.
  - Block registry `ext:*` để load block/theme ngoài.
