3️⃣ CORE MODULES & FEATURES
🏗 Multi-Tenant Architecture

Models: Tenants, Sites, Domains

Domain routing (subdomain + custom)

Per-tenant data isolation (DB row level + file prefix)

Export standalone → bundle (zip code + data)

🔐 Auth & RBAC

Roles (saasOwner → siteViewer)

2FA (email OTP / TOTP)

Social login (Google, Facebook)

Workflow-based permissions

Access lock for low roles on high workflow states

🌐 I18n System

Shared package packages/i18n

/i18n/locales/{lang}/{namespace}.json

Namespaces: admin-*, site-*, theme-*, common, validation, date-time

Auto-detect and auto-load

Locale license per site & per-user admin language

Routing: /tin-tuc, /news, …

🎨 Theme & Page Builder

Themes = config packages with tokens + sections

Page Builder sections: Hero, ServicesGrid, ProjectsCarousel, CTA, Form, etc.

Responsive per device layout

Animation presets (fade, slide, parallax, zoom)

Color palette auto generate (5–7 harmonies)

🧠 Automation & AI Assistant

Automation Rules (trigger / condition / action)

Trigger: form.submit, post.published, export.done

Action: ai.seo, ai.translate, ai.summary, webhook

AI Assistant API for content generation & query

Logging in AutomationRuns & AssistantRuns

🔍 Search & Indexing (P0)

Collection SearchIndex: siteId, locale, type, title, excerpt, slug, tags

Hooks on Posts/Pages/Products → upsert index

API /api/search?siteId=&locale=&q=

Frontend SearchBox with typeahead

Redis cache 5 min TTL per query

📈 Analytics & Metrics

Pageviews, Form submits, Automation runs

Prometheus /metrics endpoint

Grafana dashboard ready

Aggregator job per tenant / per site

🧩 Forms & Leads

Dynamic Form Builder + validation rules

Lead collection (status: new / processing / done / failed)

Rate limit + honeypot + automation trigger

AI summary draft for each lead

🪄 Workflow & Publishing

States: Draft → Pending → Published (+ custom)

Auto-transition via Automation Rules

Audit trail in AuditEvents

Rollback / versioning enabled

Rate limit on login/form/export

CSRF, CSP, WAF, MIME validation

Upload isolation per tenant path

2FA required for high-risk actions

Secrets never logged to stdout

Audit event for export + login failures

Export API → zip site code + data

Only saasOwner can export

Prometheus metrics + alert webhook
