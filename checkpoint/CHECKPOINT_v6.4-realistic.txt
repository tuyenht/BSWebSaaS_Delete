## 1️⃣ Tech Stack (Realistic, Updated)

### Runtime / Framework

- **Next.js**: **16.0.1** (App Router, RSC, PPR, Turbopack).  
  - Stable version, fully integrated with Payload 3.63.0.
- **React**: **19.0.0** (suspense/streaming, server components).
- **Payload CMS**: **3.63.0** (Next-native, KV, Jobs)  
  - Includes:
    - **Polymorphic uploads** (can relate upload field to multiple collections).  
    - **“Duplicate In [Select Locales]”** UI for multi-locale content duplication.
- **Node.js**:
  - **Production target**: Node **22.x / 24.x LTS** (meets Payload requirement Node ≥ 20.9.0).
  - **Developer machine** (current): Node **25.1.0 (Current)** – supported for local dev, not recommended as primary production runtime yet.

### Database & Storage

- **Database**: PostgreSQL 16 (multi-tenant friendly, with option to use pgBouncer).  
- **Cache / KV**: Redis 7.x (LRU, tagging for cache invalidation) – used for:
  - Payload cache adapter (cache tags).
  - App-level key/value & rate limit.
  - Next.js cache revalidation via API route `/api/revalidate` (implemented).
  - Cache tags format: `site:{siteId}:{locale}:{collection}:{identifier?}` (implemented in `packages/shared/cache/cacheTags.ts`).
- **Storage**:
  - Local disk in dev.
  - S3-compatible storage in staging/prod.
  - Upload path strategy: `{tenantId}/{siteId}/{yyyy}/{MM}/{dd}/...`

### Frontend

- React + Next.js App Router.
- Tailwind CSS, shadcn/ui, Framer Motion.
- Theme system:
  - Light/Dark mode.
  - Primary color → auto palette 5–7 tones.
- Page builder sections (Hero, Services, Projects, News, CTA, Form, etc.).
- Responsive 100%: desktop, tablet, mobile (portrait + landscape).

### Auth & Security

- Payload Auth with multi-tenant roles:
  - `saasOwner`, `saasAdmin` (platform level)
  - `siteOwner`, `siteAdmin`, `siteEditor`, `siteTranslator`, `siteViewer` (site level)
- 2FA for email login, option to enforce for high-risk operations.
- Social login (Google/Facebook) – design/docs ready.
- CSRF, rate limit, honeypot, CSP & security headers, upload hardening (MIME, size, path).

### DevOps & Infra

- Monorepo: **pnpm + Turborepo** (planned; skeleton with pnpm workspace).  
- Docker / Docker Compose for local dev:
  - `app` (Next + Payload)
  - `db` (Postgres)
  - `redis`
- Healthcheck `/api/healthz` implemented.
- Prometheus `/metrics` & Grafana – **documented**, to be added as code/config.

### AI / Automation / Observability

- AI layer design: `AiSettings` collection + Assistant API spec.
- Automation Rules engine: trigger / condition / action – schema + docs ready.
- Observability: logs, metrics, alerts – documented, not fully implemented in code.

## 6️⃣ Guidance for Code Generation Tools (Cursor, etc.)

This checkpoint is designed to be read by AI-powered code tools.

### 6.1 Priorities for Initial Implementation

When generating code, tools should prioritize:

1. **Make the repo run cleanly**:
   - `pnpm install` at root works.
   - `pnpm dev` starts Next.js dev server for `apps/saas` without TypeScript or runtime errors.
   - Health check at `/api/healthz` works.

2. **Wire Payload with full schema**:
   - `payload.config.ts` imports all collections from `packages/cms/collections`.
   - Use Postgres adapter (`@payloadcms/db-postgres`) when `DATABASE_URI` is set.
   - Provide a fallback dev mode or clear error if DB not reachable.

3. **Fix imports / path aliases**:
   - Ensure `SectionRenderer` and sections import correctly from `packages/frontend`.
   - No “Cannot find module” errors from TS or Next.

4. **Implement minimal flows**:
   - Render a real `Page` from Payload on a site route.
   - Render sections from `Page.sections` using `SectionRenderer`.
   - Implement a simple `Forms` submit endpoint storing data into `Leads`.

5. **Defer complex modules**:
   - Automation engine, AI assistant, analytics, billing, and monitoring can be implemented later, as they have full docs already.

### 6.2 Constraints & Non-goals for v6.4

- Do **not** try to implement everything at once.  
- Focus on a stable core:
  - Multi-tenant sites.
  - Theme + page builder for at least one theme (`company-industrial`).
  - Basic SEO from content.
  - Forms → Leads collection pipeline.
