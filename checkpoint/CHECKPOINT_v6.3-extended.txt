## 4️⃣ I18N STRUCTURE

```
packages/i18n/
  config/
    locales.ts
    i18n-config.ts
  locales/
    vi/, en/, ja/, zh/
      common.json
      validation.json
      date-time.json
      admin-core.json
      site-core.json
      theme-default.json
  lib/
    loadNamespaces.ts
    types.ts
```

- Copying a new locale folder auto‑registers the language (no code change required).  
- Namespaces: **admin‑\***, **site‑\***, **theme‑\***, **common**, **validation**, **date‑time**.  
- Auto detection for both Admin and Site runtime.
